# Co-Ideation refined pilot
Node 20.6+: npm install, copy .env.example to .env, insert a NEW API key, run `node --env-file=.env server.js`. Open http://localhost:3000/participant.html. Researcher viewer: /researcher.html, import exported JSON.

Assignment T0-C0 through T7-C7. Zero-based orders for tasks: S1 S2 U1 U2; S1 S2 U2 U1; S2 S1 U1 U2; S2 S1 U2 U1; U1 U2 S1 S2; U1 U2 S2 S1; U2 U1 S1 S2; U2 U1 S2 S1. Condition orders use the same permutations replacing S1,S2,U1,U2 with A,B,C,D. A=low/1, B=high/3, C=low/3, D=high/1. This is a proposed mapping, not an optimized participant allocation. Each pair includes both fidelity and quantity levels. Verify against your counterbalancing schedule.

The UI tools are native canvas equivalents, not the tldraw library. Original image prompt retained verbatim, including its volunteer-day website wording, per request. The three-suggestion questionnaire item appears only in quantity-three conditions. Q8 retains original multiple-choice options. Server automatically saves session snapshots; browser refresh recovery is not implemented. Export final JSON and store in approved storage. Render free disk is ephemeral. No live AI or browser integration test was performed. Do not collect real data before validating ethics, storage, access and API costs. Never commit .env. Public deployment requires access controls and rate limiting.
